# jdnotioncsv

Notion CSV Fixer & Splitter — 구글 스프레드시트에서 내보낸 CSV를 노션 데이터베이스로 정상 업로드되게 고쳐 주는 단일 HTML 웹앱입니다. `index.html` 파일 하나만 브라우저로 열면 되고, 파일은 외부로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 주요 기능

- 셀 내부 개행을 `\n`으로, 행 구분을 `\r\n`으로 통일해 노션 파서가 셀을 쪼개지 않게 만듭니다.
- 제목(Title) 열을 지정하면 그 열을 파일의 첫 번째 열로 옮깁니다.
- 업로드 전 점검 결과와 미리보기를 보여 줍니다.
- 노션 한계(5MB, 20,000행)를 넘는 파일을 행 단위로 나눠 내려받습니다.

## "하나 이상의 열을 제목 속성으로 설정해야 합니다" 문제

노션의 `CSV 헤더 매핑` 화면은 열 하나가 제목 속성으로 잡혀야만 미리보기를 그립니다. 자동 지정이 실패하는 원인과 이 도구의 대응은 다음과 같습니다.

| 원인 | 대응 |
| --- | --- |
| 헤더 이름 안의 줄바꿈이 CSV 첫 줄을 두 줄로 쪼갬 | 헤더의 줄바꿈과 탭을 항상 공백으로 치환 |
| 이름이 없는 첫 열 | 빈 헤더에 이름 자동 부여 |
| 이름과 값이 모두 빈 열이 제목 자리를 차지 | 해당 열 제거 |
| 숫자나 날짜만 있는 첫 열이 숫자·날짜 속성으로 매핑됨 | 제목 열 직접 지정 기능과 경고 |
| 제목 열에 빈 값이 섞여 있음 | 빈 제목을 `무제 N`으로 채우는 옵션 |

## 그 밖에 고친 결함

- 짝이 맞지 않는 따옴표를 만나면 그 문자를 조용히 삭제하던 파서를 고쳤습니다. 셀 안의 따옴표는 문자로 보존하고, 닫는 따옴표가 없는 셀은 행 구조를 지키며 복구합니다.
- 데이터 행이 헤더보다 넓을 때 넘치는 열을 잘라 버리던 동작을 고쳐, 열을 추가하고 사실을 알립니다.
- 모든 행을 같은 칸 수로 맞추도록 항상 정규화합니다. 동작하지 않던 "부족한 열 자동 채움" 옵션은 제거했습니다.
- 읽을 행이 없는 파일에서 이전 결과가 그대로 남던 문제를 고쳤습니다.
