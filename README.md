# jdnotioncsv

Notion CSV Fixer & Splitter — 구글 스프레드시트에서 내보낸 CSV를 노션 데이터베이스로 정상 업로드되게 고쳐 주는 단일 HTML 웹앱입니다. `index.html` 하나만 브라우저로 열면 되고, 파일은 외부로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 주요 기능

- 원본 구분자(쉼표·세미콜론·탭·파이프)를 자동 감지하고 항상 쉼표로 저장합니다.
- 헤더 행을 직접 고를 수 있습니다. 시트 맨 위의 제목 배너 행은 자동으로 건너뜁니다.
- 제목(Title) 열을 지정하면 그 열을 첫 번째 열로 옮기고, 값을 한 줄로 폅니다.
- 셀 내부 개행을 `\n`으로, 행 구분을 `\r\n`으로 통일합니다.
- 노션이 실제로 읽게 될 첫 줄을 그대로 보여 주는 진단 패널이 있습니다.
- 노션 한계(5MB, 20,000행)를 넘는 파일을 행 단위로 나눠 내려받습니다.

## "하나 이상의 열을 제목 속성으로 설정해야 합니다"

노션의 `CSV 헤더 매핑` 화면은 열 하나가 제목 속성으로 잡혀야 미리보기를 그립니다. 원인은 파일 쪽과 화면 쪽 두 갈래입니다.

| 파일 쪽 원인 | 대응 |
| --- | --- |
| 헤더 이름 안의 줄바꿈이 첫 줄을 두 줄로 쪼갬 | 헤더의 줄바꿈과 탭을 항상 공백으로 치환 |
| 보이지 않는 문자만 들어 있는 헤더 | 제로 폭 문자와 제어 문자 제거 |
| 이름이 없는 첫 열 | 빈 헤더에 이름 자동 부여 |
| 이름과 값이 모두 빈 열이 제목 자리를 차지 | 해당 열 제거 |
| 숫자나 날짜만 있는 첫 열 | 제목 열 직접 지정과 경고 |
| 제목 값에 줄바꿈이 섞임 | 제목 열 값을 항상 한 줄로 변환 |
| 제목 열에 빈 값이 섞임 | 빈 제목을 `무제 N`으로 채우는 옵션 |
| 쉼표가 아닌 구분자로 저장된 파일 | 구분자 자동 감지 후 쉼표로 재저장 |
| 첫 행이 제목 배너인 시트 | 헤더 행 자동 감지와 수동 선택 |
| 모든 열이 길고 여러 줄인 본문뿐 | 앞부분을 따온 짧은 제목 열 자동 생성 (원본 열은 유지) |

파일이 멀쩡해도 매핑 목록에서 제목이 지정되지 않은 상태면 같은 메시지가 남습니다. 그때는 첫 번째 열의 속성 드롭다운을 직접 `제목`으로 바꾸면 미리보기가 살아납니다.

파일이 노션 한도(5MB, 20,000행)를 넘어도 같은 메시지가 나옵니다. 노션은 업로드 자체는 받아 주지만 미리보기를 만들지 못하고, 화면에는 제목 속성을 지정하라는 안내만 남습니다. 한도를 넘으면 단일 다운로드 버튼이 경고 표시로 바뀌고 분할 다운로드를 안내합니다.

원인을 가르는 방법은 두 가지입니다.

- **출력 재검증**: 변환 결과를 만드는 코드와 분리된 표준 CSV 파서로 다시 읽어, 열이 정확히 나뉘는지 진단 패널에 표시합니다.
- **노션 시험용 최소 파일**: 2열 3행에 줄바꿈도 따옴표도 BOM도 없는 파일을 내려받아 먼저 올려 봅니다. 이 파일에서도 같은 메시지가 나오면 원인은 변환 결과가 아니라 매핑 화면입니다.

## 그 밖에 고친 결함

- 짝이 맞지 않는 따옴표를 조용히 삭제하던 파서를 고쳤습니다. 셀 안의 따옴표는 문자로 보존하고, 닫는 따옴표가 없는 셀은 행 구조를 지키며 복구합니다.
- 데이터 행이 헤더보다 넓을 때 넘치는 열을 잘라 버리던 동작을 고쳤습니다.
- 모든 행을 같은 칸 수로 항상 정규화합니다. 동작하지 않던 "부족한 열 자동 채움" 옵션은 제거했습니다.
- 읽을 행이 없는 파일에서 이전 결과가 그대로 남던 문제를 고쳤습니다.
